# Changelog

## 0.1.0 (2026-09-29)

First release.

- Six checks: citation grounding, citation coverage, phantom citations, PII, required disclosures, prohibited language
- `finance` and `general` policy packs with regulatory references
- Hash-chained audit log with `verify-log`
- Optional LLM judge for uncertain grounding
- CLI with table and JSON output, Python API and a pytest helper
